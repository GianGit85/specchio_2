# specchio_2

Pagina "sorpresa" per lo spettacolo **Come fecero i Greci** (Copia Incolla APS, 20 novembre 2026).
Lo spettatore inquadra il QR code, strofina la sfera di cristallo, scopre che la cosa più importante
dello spettacolo è lui e può condividere la foto nella storia Instagram.

- `index.html`: tutta la pagina (nessuna libreria esterna)
- `assets/`: logo e font (Luckiest Guy e Special Elite, licenza Apache 2.0)
